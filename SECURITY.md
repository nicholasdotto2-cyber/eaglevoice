# Security policy

eagleVoice is a personal prototype maintained by one person. There are no releases, no
installer and no support guarantees; only the latest state of the `main` branch is looked at.

## Reporting a vulnerability

Please report security problems privately through GitHub: open the repository's **Security**
tab and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Include what you found, the steps to reproduce it and the commit you tested. You will get an
answer when the report has been read; there is no fixed response time.
